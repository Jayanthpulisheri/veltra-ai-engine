## ⚡ Key Highlights
* **Deterministic Interception:** Intercepts and validates shell commands, file manipulations, and execution payloads *before* they reach the runtime process.
* **Sub-3ms Overhead:** Zero noticeable latency added to LLM tool execution loops.
* **Zero Dependency Lock-In:** Plug-and-play middleware that works with **AutoGPT**, **OpenAI SDK**, **Pydantic AI**, and custom agent frameworks.
* **Command & Secrets Guardrails:** Out-of-the-box filtering for destructive commands (`rm -rf`, system wipes, unauthorized directory reads) and sensitive env leakage.

Basic Usage
Python
from veltra import VeltraGuardrail

# Initialize Veltra pre-execution engine
guard = VeltraGuardrail()

# Incoming payload generated by AI Agent
command = "echo 'cleaning' && rm -rf /tmp/test_dir"

# Pre-execution validation check
result = guard.validate(command)

if not result.is_allowed:
    print(f"[BLOCKED] > SECURITY_BLOCK: {result.reason}")
else:
    # Execute command safely in local runtime
    guard.execute(command)

🔌 Framework Integration Guides
1. Pydantic AI Integration
Use Veltra directly inside Pydantic AI's native ToolGuardrail hook:

Python
from pydantic_ai import Agent
from veltra import VeltraGuardrail

guard = VeltraGuardrail()

def pre_execution_hook(ctx, tool_name: str, tool_args: dict):
    if tool_name == "terminal_execute":
        check = guard.validate(tool_args.get("command", ""))
        if not check.is_allowed:
            raise ValueError(f"Veltra Security Intercept: {check.reason}")
    return tool_args
