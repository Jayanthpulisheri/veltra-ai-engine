# Veltra AI Engine v1.0 (MVP)

> 🎬 **Demo Video:** [Watch Veltra AI in Action (57s)](https://www.loom.com/share/d4fce3a6cbe3469680b9aaf92be73b61)

An enterprise-grade, autonomous software execution and VFX generation engine powered by Groq API and LLM-driven terminal control loops.

## Features
- **Autonomous Shell Execution:** Multi-step tool use, code writing, and system command execution.
- **VFX Rendering:** Dynamic Pillow-based media and graphics generation.
- **Security Sandboxing:** Hardened command blocklist and persistent JSON auditing (`veltra_audit.log`).
